# 判定文章・速度順・フィードバック

出典: 2026-10-03ユーザー依頼。判定を「『B』は『A』です／ではありません」で色分け、応答が速い順に表示、良かった／悪かったのフィードバックを記録。

- [x] フェーズ1: 表示・整列・永続記録とダウンロードを実装。npm test、専用仮想環境でSQLiteの並列再送・重複防止・修正履歴・再読込・不正入力を確認。Edge模擬試験で速度順・文章の対応・色・保存失敗の再送・ダウンロードと既存のモデル切り替え／集計を確認。
- [ ] フェーズ2: 実GPU・実ブラウザーで確認し、稼働サーバーへ反映して記録。

評価完了時に応答時間昇順へ整列（同値は元の順序）。フィードバックは判定時のA/B・モデル・確率・応答時間・日時に結び付け、SQLiteへ履歴追記する。保存失敗を成功扱いしない。試験用DBと利用者DBを分離。利用者DBはdev/feedbackに置いてGitから除外する。
