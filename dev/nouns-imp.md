# 名詞判定画面の実装計画

出典: 2026-10-03 のユーザー依頼。「これは{A}ですか？」に対して約10個の{B}を評価する画面と、A/Bに使う約1,000個のランダムな名詞。

- [x] フェーズ1: 日本語名詞1,000語を作成し、重複・件数を確認してコミット。
- [x] フェーズ2: A入力、B10件の編集・抽選・逐次判定、結果一覧を実装し検証・コミット。
- [ ] フェーズ3: 実GPUの10件評価と画面確認、文書更新、稼働中サーバーへの反映。

既存の日本語サンプル画面は保持する。名詞判定は/nouns。A/Bは同じ辞書から選び、Bは重複なしで10語を抽選。初期表示は動物の分類を試す例。GPUリクエストは並列化せず、Jev形式のnoulを1件ずつ送信する。辞書の分類は単語整理用であり正解ラベルとして推論に渡さない。
