# v0.10.2 画像一括処理の改善と拡大プレビュー

ユーザー指示：転送前の解像度確認・完了行のみ更新による高速化、体感と時間表示の差の改善、クリック拡大。

- [x] JPEG SOF、PNG IHDR、WebP VP8/VP8L/VP8Xのヘッダーから寸法を取得。1600万画素超・8MB超を送信前に除外。既存サーバー検証は維持。
- [x] 一括処理の毎回の全表再作成を完了行の更新へ変更。推論の並列化や意図的待機は追加しない。
- [x] ブラウザー側で処理時間を測定し、サーバーの推論時間と区別。フォルダ全体の経過時間も表示。
- [x] サンプル・フォルダ・単画像のクリック拡大。閉じる・Esc・背景クリックに対応。
- [x] 模擬ブラウザー試験と実APIの5画像試験が成功。JPEG/PNG/WebPの解像度ヘッダー試験、超過画像でAPI呼び出しが増えないこと、拡大とEsc、JSON時間保存を確認。

実測例（Qwen 2B）：sample1は処理435.7ms／推論356.6ms、sample2は367.3／344.4、sample3は310.3／294.4、sample4は365.9／332.9、sample5は366.1／348.3。機種や負荷によって変動する。変更前との同条件速度比較は行っておらず、速度改善率は断定しない。

生データはdev/testing/output/folder-live.json、画面はfolder-live.png（Git対象外）。実行はnode tests/photos-browser.cjsとnode tests/photos-folder-browser.cjs。後者はLIVE_URL設定で実API。起動済みサーバーはそのまま、ページ再読み込みで反映。
